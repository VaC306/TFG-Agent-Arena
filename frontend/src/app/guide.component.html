01

El punto de partida

Elige qué quieres probar.

En Comparar, da un nombre a tu prueba y elige entre un modelo o dos modelos.

Un modelo: usa el mismo modelo con dos prompts y entradas independientes. Dos modelos: ambos reciben la misma entrada y archivos; puedes elegir un prompt para cada uno.

Si cambias el prompt y los datos a la vez, las diferencias no se pueden atribuir solo al prompt.

02

Quién responde y cómo

Configura los agentes.

Elige Simulado para conocer la herramienta o Ollama para ejecutar modelos instalados en tu ordenador. Después, selecciona los modelos en los desplegables de A y B.

Un prompt es una instrucción sobre cómo responder. Elige una plantilla, como Resumen o Extracción JSON, y abre «Editar instrucciones» si quieres ajustarla.

El simulador comprueba el funcionamiento de la plataforma. Para medir respuestas reales necesitas Ollama activo y modelos instalados. Las imágenes requieren un modelo con visión.

03

Tu material de trabajo

Añade tus propios datos.

Con Entrada manual y adjuntos, escribe qué quieres que haga el modelo. Puedes adjuntar TXT, JSON, CSV o imágenes PNG, JPG y WebP.

Para probar muchos casos, elige Importar dataset. Descarga la plantilla, rellena tus casos y sube un CSV o JSONL. Revisa la vista previa antes de ejecutar.

Adjuntos: hasta 4 archivos por entrada y 1 MiB por archivo. Dataset: hasta 100 casos de texto y 1 MiB. Cada caso del dataset se envía a ambos agentes.

04

Qué significa hacerlo bien

Define cómo evaluar.

Si conoces la respuesta correcta, añade una respuesta esperada. Elige Texto exacto para respuestas concretas o JSON equivalente para comparar datos estructurados, ignorando formato y orden de claves.

Si buscas un resumen o una respuesta abierta, elige Sin evaluación automática y revisa las respuestas tú mismo. Verás tiempos y recursos; la calidad aparecerá como sin evaluar. Una coincidencia automática no mide calidad semántica.

Elige de 1 a 10 repeticiones. Cada caso se ejecutará ese número de veces para cada agente.

En «Condiciones de ejecución» puedes fijar temperatura, semilla, contexto y límites iguales para ambos agentes. Usa también el mismo prompt y los mismos datos para comparar solo modelos.

05

Todo preparado

Ejecuta la comparación.

Revisa los modelos, los prompts y las entradas. Pulsa Ejecutar comparación: se guarda la configuración y se abre Resultados.

Las ejecuciones pasan por En cola, En curso y un estado final. A y B se ejecutan de forma secuencial, y la página actualiza su progreso automáticamente.

Si todo permanece en cola, comprueba que el worker esté arrancado. Los comandos para lanzar API, frontend y worker están en el README del proyecto.

06

De los datos a tu criterio

Explora lo que ha pasado.

En Resultados, compara las respuestas de A y B, el tiempo medio y el éxito cuando haya evaluación. Abre Ver traza para consultar los eventos de una ejecución.

Usa Exportar CSV para analizar las métricas. Abre Evaluación y condiciones de esta prueba para consultar sus límites y descargar el informe reproducible con configuración, datos e identidad de modelos. El Historial te permite volver a tus pruebas.

Tu perfil conserva modelos, prompts y parámetros. Las entradas y los archivos se guardan con la comparación cuando la ejecutas. Una respuesta completada no significa, por sí sola, que sea correcta.
