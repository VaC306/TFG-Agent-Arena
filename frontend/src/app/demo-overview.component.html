06 / El TFG

Comparar agentes con evidencia.

Agent Arena Local conserva qué recibió cada agente, qué herramientas utilizó, qué respondió y bajo qué condiciones. El objetivo es estudiar calidad y coste sin perder los fallos por el camino.

Aplicación local completa

  1. AngularConfigura y explora
  2. FastAPIValida y planifica
  3. SQLiteCola y evidencia
  4. Worker PythonRunner, herramientas y evaluador
  5. OllamaInferencia local

API y worker separados. Los resultados vuelven a SQLite para consulta/exportación; A/B se ejecutan secuencialmente.

Esta demo

  1. AngularLa misma interfaz en modo consulta
  2. JSON estáticosSelección revisada de resultados
  3. Sites privadoAcceso gestionado por la plataforma

Aquí no se ejecutan FastAPI, SQLite, un worker ni Ollama.

IMPLEMENTADO

Un flujo completo

Comparaciones A/B, referencias, estados, herramientas, informes, biblioteca y campañas con diseño fijado en la aplicación local.

EVIDENCIA REAL

Pruebas pequeñas con Ollama

Dos modelos Qwen, suites de texto, JSON, pedidos y adjuntos, además del diagnóstico de herramientas. Cada observación conserva su alcance.

VALIDADO CON SIMULACIÓN

Comportamiento de la plataforma

Cola, cancelación, trazas y recorridos de interfaz. No prueba calidad ni velocidad de modelos reales.

PENDIENTE

Evaluación más amplia

Más casos revisados, repeticiones e infraestructura para estudios controlados. No hay campañas longitudinales ni rankings disponibles en esta demo.

Cómo leer la evidencia

  • Desarrollo y evaluación reservada se muestran por separado.
  • Calidad, cobertura, formato y errores responden a preguntas diferentes.
  • El tiempo total puede incluir preparación y carga; no es velocidad pura de generación.
  • La semilla fija no garantiza determinismo; el host no estaba aislado.
  • Una muestra pequeña no demuestra superioridad general de un modelo.

Estado de esta selección: 13/10/2026. Sin acceso al razonamiento interno del modelo.
